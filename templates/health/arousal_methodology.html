How today's number is produced

  1. Today's wrist heart-rate samples are read from the Google Health API (the same cached fetch the rest of the dashboard uses).
  2. They are cut into {{ window_seconds }}-second windows, stepping every {{ step_seconds }} seconds — the same geometry the model was trained on. A window holding fewer than {{ min_samples }} readings is dropped rather than described by statistics computed from almost nothing.
  3. Five features are computed per window: mean, standard deviation, minimum, maximum and slope of the heart rate.
  4. The model labels each window, and the card reports the label that won the most windows.
  5. Before that label is shown, each feature is compared against the range seen in training, and the comparison is displayed with it.

Why there is no accuracy figure for your own data

There is no ground truth. Nobody recorded which minutes of your days were stressful, so there is nothing to score the predictions against. The cross-validated numbers above describe how the model performs on the laboratory dataset it was trained on — they are not a claim about how it performs on you.
